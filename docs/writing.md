# UI ライティング

画面に出る日本語の書き方。**読む量を減らすことが目的**であって、丁寧に書くことが目的ではない。

コンポーネントの選び方は [components.md](./components.md)、文字サイズは [typography.md](./typography.md)、
メニューのラベルは [navigation.md](./navigation.md) を参照。

## 0. 冗長さの正体は「情報ゼロの1文目」

UI テキストが読みにくくなる原因の大半は、難しい言葉でも長い文でもなく、
**すでに画面に出ていることをもう一度書いている**ことにある。

```
カードタイトル: スタッフ
説明:          スタッフの情報登録・編集・削除を管理します      ← タイトルの言い換え。情報ゼロ

ラベル:         返却理由名
プレースホルダ: 返却理由名を入力...                          ← ラベルの繰り返し。しかも入力すると消える
```

利用者は**説明文を読み飛ばすようになる**。すると本当に必要な注意書き（制約・影響範囲）も読まれない。
冗長さの害は「長い」ことではなく、**読まれなくなること**。

原則は1つ。**すでに画面に出ていることを書かない。**

## 1. ラベルは名詞句

- **動詞を付けない**。`営業時間を設定` → `営業時間`
- 画面タイトル・セクション見出し・フィールドラベルすべて同じ
- 句点を打たない（§8）

| ❌ | ✅ |
|---|---|
| 営業時間を設定 | 営業時間 |
| ユーザーの管理 | ユーザー |
| 支払方法の選択 | 支払方法 |

> 「何をする画面か」は見出しではなく**画面の中身**が示す。見出しに動詞を足しても情報は増えない。

## 2. 説明文は「ラベルから読み取れないこと」だけ書く

**ラベルの言い換えしか書けないなら、説明文を書かない。** 空欄のままにしてよい。

書く価値があるのは次の3つだけ。

| 書くべきこと | 例 |
|---|---|
| **制約・入力形式** | 24 時を超える場合は `25:00`（翌 1:00）のように入力します |
| **影響範囲** | 画面の表示だけが変わります。保存済みのデータは変わりません |
| **未設定時の既定挙動** | 設定しない場合はコース料金がそのまま使われます |

### 2-1. 1文目を疑う

説明文を書いたら、**1文目を消しても意味が通るか**を確かめる。通るなら消す。

```
❌ 店舗の営業時間を設定します。全曜日共通です。24 時を超える場合は 25:00（翌 1:00）のように入力します。
    ↑「営業時間」という見出しの下にあるので 1 文目は情報ゼロ

✅ 全曜日共通です。24 時を超える場合は 25:00（翌 1:00）のように入力します。
```

### 2-2. 長い説明は画面の作りを疑う

説明が3文を超えたら、たいてい**画面が分かりにくい**ことの埋め合わせになっている。
文章を削るのではなく、フィールドを分ける・既定値を入れる・そもそも設定項目を無くせないかを先に考える。

## 3. プレースホルダを説明の代用にしない

プレースホルダは**入力すると消える**ので、常に必要な情報を置いてはいけない。

| 用途 | 可否 |
|---|---|
| **入力例**（形式がラベルから分からないとき） | ✅ `090-1234-5678` / `2026-04-01` |
| ラベルの繰り返し | ❌ ラベル `氏名` に対して `氏名を入力...` |
| 必須・任意の表示 | ❌ ラベル側に出す |
| 制約の説明 | ❌ 説明文（§2）に出す |

**入力例が思いつかないなら空にする。** 空のプレースホルダは何も損なわない。

## 4. エラーは次の行動を書く

利用者が知りたいのは「何が起きたか」ではなく「**どうすれば進めるか**」。

| ❌ 状態だけ | ✅ 次の行動 |
|---|---|
| データの読み込み中にエラーが発生しました | 読み込めませんでした。時間をおいて再読み込みしてください |
| 入力値が不正です | 半角数字で入力してください |
| 権限がありません | この操作には管理者権限が必要です。管理者に依頼してください |

### 4-1. 必須エラーは `〜を入力してください`

`〜を入力してください` の形で統一する。**動詞は操作に合わせる**。

| 入力方式 | 文言 |
|---|---|
| テキスト・数値 | `氏名を入力してください` |
| 選択・日付 | `支払方法を選択してください` |
| ファイル | `領収書を添付してください` |

### 4-2. 原因が利用者にないエラーは謝らない・責めない

- 通信・サーバ起因: 何が起きたかを短く言い、再試行の手段を示す
- 入力起因: 「不正」「誤り」ではなく**正しい形**を示す

## 5. ボタンは何が起きるかを書く

- **`OK` `送信` `実行` のような汎用語を使わない**。押した結果を動詞で書く
- 文言は定数から引く（`BUTTON_LABELS` 等）。画面ごとに文字列を直書きしない（[components.md](./components.md)）
- 句点を打たない（§8）

| ❌ | ✅ |
|---|---|
| OK | 削除する / 保存する |
| 送信 | 申請を提出する |
| はい / いいえ | 取り消す / 戻る |

## 6. 空状態は「状況 + 次の一手」

状況の説明だけで終わらせない。**次に押せるものを置く。**

```
❌ データがありません

✅ まだ申請がありません
   [ 新規申請を作成する ]
```

フィルタの結果が 0 件なら、**フィルタのせいだと分かるように書く**（「条件に一致する申請がありません」）。
データが本当に無いのか、絞り込んだ結果なのかで次の行動が変わる。

## 7. 確認ダイアログ

| 位置 | 書くこと |
|---|---|
| タイトル | **対象**を含む短い問い（`この申請を削除しますか？`） |
| 本文 | **結果**。特に元に戻せるかどうか（`削除すると元に戻せません`） |
| ボタン | 動詞（`削除する` / `キャンセル`）。`はい` `いいえ` は使わない |

本文に「本当によろしいですか？」と書かない（情報がない）。**何が起きるか**を書く。

## 8. 文体と表記

### 8-1. 敬体（です・ます）

UI テキストは**敬体**で統一する。管理画面と利用者向け画面で書き分けない
（境界の判断が毎回発生し、必ずブレるため）。

### 8-2. 句点は「文には打つ、句には打たない」

述語で終わる**文**には `。` を打ち、名詞・動詞で言い切る**句**には打たない。
機械的に判定できるので迷わない。

| 種類 | 句点 | 例 |
|---|---|---|
| 説明文・エラー・本文 | **打つ** | `設定しない場合はコース料金がそのまま使われます。` |
| ラベル・見出し | 打たない | `営業時間` |
| ボタン | 打たない | `削除する` |
| バッジ・チップ | 打たない | `振込完了` |
| プレースホルダ | 打たない | `090-1234-5678` |

複数文になるときは**すべての文に**打つ（最後だけ打つ、をやらない）。

### 8-3. `〜してください` は指示のときだけ

| 内容 | 書き方 |
|---|---|
| 利用者に行動してもらう | `〜してください`（`半角数字で入力してください`） |
| システムの挙動を説明する | `〜します`（`設定した内容は次回の集計から反映されます`） |

説明文を全部 `〜してください` で書かない。**指示が混ざると、どれが必須の操作か分からなくなる。**

### 8-4. 表記の統一

- 数字は**半角**。英字も半角
- 半角と全角の間に空白を入れない（`24時` であって `24 時` ではない）。ただし**単位や記号の可読性のために入れている既存表記は揃える側に合わせる**
- 丸括弧は全角 `（）`、コード・識別子まわりは半角 `()`
- 感嘆符を使わない

## 9. 同じ概念に2つの言葉を使わない

`ユーザー` と `利用者`、`削除` と `破棄`、`申請` と `リクエスト` を混ぜない。
**プロダクトごとに用語集を1箇所に持ち、そこを参照する**（文言定数ファイルがその役割を兼ねてよい）。

新しい言葉を導入する前に、既存の文言カタログを検索して**同義語が無いか**を確認する。

## 10. レビュー用チェックリスト

差分行を対象に当てる（既存の全面書き換えは強制しない。**触った画面のついでに直す**）。

- [ ] 説明文の**1文目**がラベル・見出しの言い換えになっていないか（消しても通らないか）
- [ ] プレースホルダがラベルの繰り返しになっていないか（入力例か、空か）
- [ ] ラベルに動詞が付いていないか（名詞句か）
- [ ] エラーに**次の行動**が書かれているか
- [ ] ボタンが `OK` `送信` `はい/いいえ` になっていないか
- [ ] 空状態に**次に押せるもの**があるか
- [ ] 句点が「文には打つ、句には打たない」になっているか
- [ ] `〜してください` を、指示でないところに使っていないか
- [ ] 既存の文言カタログに**同義語**が無いか
