# タイポグラフィ

**独自の `fontSize` スケールを定義しない。** Tailwind 標準スケールを「用途」にマップして使う。
サイズの種類を増やすのではなく、用途ごとにどのクラスを使うかを決め打ちすることで一貫性を出す。

to B（業務画面）と to C（一般利用者向け）で既定が分かれる点は [design.md](./design.md) にまとめている。

## 0. フォント

| 種類 | 規定 |
|------|------|
| Sans | **Noto Sans JP**（＋システムフォールバック）。core の Tailwind アダプタが `font-sans` に設定済み |
| Mono | 各プロダクトで 1 つ設定する（Tailwind 既定のままでよい） |
| フォントファイルの配信 | **各プロダクトの責務**（自前配信、`next/font` 等）。core は配信しない |
| 欧文用フォント | Noto Sans JP の前に足すのはプロダクト側の上書きで可（書き方は [README](../README.md)） |

`body` に Sans を適用しておく。本文で `font-sans` を明示する必要はない。

## 1. サイズと行間の使い分け

| 役割 | クラス | 行間 | 補足 |
|------|--------|------|------|
| ページ見出し（h1 相当） | `text-2xl md:text-3xl font-bold` | `leading-normal md:leading-snug` | スマホ 24px / `md` 以上 30px。**1画面に1つ**。to B の `<h1>` は上の帯に置き、サイズは [navigation.md](./navigation.md) §9-1 |
| セクション見出し（h2 相当） | `text-xl font-semibold` | `leading-normal` | Card のタイトル等、まとまりの長 |
| 小見出し（h3 相当） | `text-lg font-medium` | `leading-normal` | サブセクション |
| 本文・フォーム値 | `text-base` | 文章は `leading-relaxed` | 既定。多くの入力・表示はこれ。**入力欄の文字は `text-base` 固定**（§1-2） |
| 補助テキスト・ラベル・キャプション | `text-sm` | 文章は `leading-relaxed`、密な業務画面は `leading-tight` | フィールドラベル、説明文、テーブルセル |
| 注釈・メタ情報 | `text-xs` | 1 行なら既定のまま | タイムスタンプ、件数、軽微な補足 |
| 主役の数値 | `text-4xl font-bold` | `leading-none` | 統計の大きな数字、表示専用の PIN など。**見出しには使わない** |
| 転記・目視照合する英数字文字列 | `font-mono`（`text-*` と併用） | — | API キー・URL・トークン等。0/O・1/l の誤読防止 |

**業務画面（to B）では、迷ったら `text-sm`。** 業務画面の情報密度では、ラベル・テーブルセル・説明文の大半が
`text-sm` に収まる。「本文なのか補助なのか」で迷ったときは `text-sm text-muted-foreground` に寄せる。
to C の既定（本文 `text-base`、補助 `text-sm`）は [design.md](./design.md) の to B / to C の節を参照。

### 1-1. サイズの下限は 12px

- **下限は `text-xs`（12px）。** 12px を使ってよいのは**注釈・メタ情報だけ**。
- **本文と操作要素（ボタン・リンク・入力）は `text-sm`（14px）以上。** 押せるもの・読ませるものを小さくしない。
- ボトムタブバーのラベルだけは、アイコンと併記する短い語なので `text-xs` でよい（[navigation.md](./navigation.md)）。
- 12px 未満は §5 の例外（高密度グリッド）だけ。

### 1-2. 入力欄の文字は `text-base`（16px）固定

`Input` / `Textarea` / `Select` 等、入力欄の中の文字は**画面の密度にかかわらず `text-base`**。
iOS は 16px 未満の入力欄にフォーカスすると画面を拡大し、入力後も拡大したままになる。
ラベル・説明文・エラーは §1 の表どおり `text-sm` でよい（[forms.md](./forms.md)）。

## 2. 行間は用途で決める

行間はデバイス（スマホ / デスクトップ）では分けず、**用途**で決める。

| 用途 | クラス | 値 |
|------|--------|-----|
| 読ませる文章（説明文・本文・お知らせ。複数行になるもの） | `leading-relaxed` | 1.7（core が上書き） |
| 見出し（`text-lg`〜`text-2xl`） | `leading-normal` | 1.5 |
| 大見出し（`text-3xl` 以上） | `leading-snug` | 1.375 |
| 密な業務画面（テーブルセル・ラベル・複数行になる短い補足） | `leading-tight` | 1.3（core が上書き） |
| 1 行前提の UI（ボタン・バッジ・タブ） | `leading-none` または `text-*` 既定のまま | 1.0 |

**上の用途では `leading-*` を明示する。** Tailwind の `text-*` は既定の行間を内包していて
（`text-base` 1.5、`text-2xl` 約 1.33、`text-3xl` 1.2）、日本語の見出し・本文には詰まりすぎる。
`text-*` だけを書くと、その既定の行間がそのまま当たる。

> 根拠: デジタル庁デザインシステムは本文 16〜17px に 1.7、見出し 20〜32px に 1.5、36px 以上に 1.4、
> 業務画面向けに 1.2 / 1.3、1 行の UI に 1.0 を割り当てている。本文は少なくとも 1.5 倍を推奨。

### 2-1. 段落間と行長（読み物）

| 項目 | 規定 |
|------|------|
| 行長 | 1 行を**全角 40 字程度まで**に抑える。本文の親に `max-w-prose` を付ける |
| 段落間 | 親で `space-y-6`（L / 24px）。本文は `leading-relaxed` と組み合わせる |

段落間の目安は**文字サイズの 2.25 倍以上**（`text-base` なら 36px）。
余白は [spacing.md](./spacing.md) の段から選ぶため L（24px）に丸めるが、`leading-relaxed` の行は
上下に 0.35em ずつ余白を持つので、段落どうしの**見た目の間隔は 24px + 0.7em ≒ 35px** になり目安に届く。
LL（32px）は段落間には使わない。

行長の上限は読み物（説明文・お知らせ・規約等）に付ける。フォーム・テーブル・カードの中は親の幅に従う。
ページ全体の最大幅は [layout.md](./layout.md) を参照。

## 3. ウェイトと色の組み合わせ

- **強調はウェイトで表現する**（`font-medium` / `font-semibold` / `font-bold`）。**色での強調は最小限**にする。
  色は意味（成功・警告・エラー・リンク）を伝えるために取っておく。
- 補助テキストは `text-sm text-muted-foreground` をセットで使う（色は [color.md](./color.md) のトークン）。
- 一画面で使う見出しサイズの段階は **2〜3 段まで**に抑え、サイズの乱立を避ける。
- ウェイトも 3 種（`normal` / `medium` / `semibold`）＋ページ見出し・主役の数値の `bold` までに抑える。
- 字間（letter-spacing）は定義しない。Tailwind 既定のまま使う。

## 4. mono の使いどころ

`font-mono` は **転記・目視照合する英数字文字列だけ**に使う。

| 用途 | mono |
|------|------|
| API キー、トークン、URL、ハッシュ、識別コード（人が目で照合する） | ✅ 使う |
| 金額、ポイント、件数などの数値 | ❌ 使わない（Sans のまま） |
| ID（画面上で照合しない内部 ID） | ❌ 使わない |

金額や数値を等幅にしたくなるのは「桁を揃えたい」からだが、それは**右寄せ**と
`tabular-nums`（`font-variant-numeric`）で解決する。書体を変える必要はない。

## 5. やらないこと

- ❌ `style={{ fontSize: "13px" }}` のような px 直書き → §1 の表のクラスから選ぶ
- ❌ `text-[15px]` などの任意値クラス → 標準スケール（`text-sm` / `text-base` 等）に寄せる
- ❌ 本文・ボタン・リンクに `text-xs` → `text-sm` 以上（§1-1）
- ❌ 入力欄に `text-sm` → `text-base` 固定（§1-2）
- ❌ 複数行の文章を `text-*` 既定の行間のまま置く → `leading-relaxed` を明示（§2）
- ❌ `font-family` の直接指定 → Sans は既定、等幅は `font-mono`
- ❌ `tracking-*` で字間を詰める・広げる → Tailwind 既定のまま
- ❌ 独自の `fontSize` トークンを Tailwind config に足す → 標準スケールで足りる
- ❌ 金額・ポイント・ID 等の数値への `font-mono`

### 例外

サイズの下限（§1-1）の**唯一の例外**として、高密度グリッド（絶対配置・px 寸法のセルやバーと同居する
最小ラベル）に限り、`text-[10px]` 相当の任意値やインライン `fontSize` を許容する。
12px 未満の表示が物理的に必要で、標準スケールでは収まらないケースのため。

**乱用しない。** 一覧・フォーム等、密度制約のない箇所では通常どおり標準スケールに従う。
